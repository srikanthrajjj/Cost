# CostReno - Brand Guidelines

## Colors

### Primary Color
- **Hex:** #082A4B (Dark Navy Blue)
- **Usage:** Headers, navigation, primary text, borders, general UI elements
- **Tailwind:** `bg-primary`, `text-primary`

### Secondary/Accent Color  
- **Hex:** #03A44D (Green)
- **Usage:** CTAs, important action buttons, highlights, success states
- **Tailwind:** `bg-accent`, `text-accent-foreground`
- **IMPORTANT:** Use green SPARINGLY - only for key call-to-action buttons like:
  - "Start Planning" (header)
  - "Calculate My Estimate" (hero)
  - "Subscribe Free" (newsletter)
  - Success messages

### Color Application Rules
1. **Primary (Dark Blue):** Default for most UI elements
2. **Accent (Green):** Only for important action buttons that drive conversion
3. **Never use green for:** Secondary buttons, links, text, backgrounds
